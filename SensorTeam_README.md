The updates proposed by the C3PO sensor team were to improve the efficiency of the sensors ability to monitor Sunny Day Flooding by the following;
Reduce size of Conductivity and Temperature probes being used in the C3PO sensor
Future suggestions for adding a pressure probe

The updates made include;
code change 1 to a 0 in code for publishing
new wiring diagram, 
images of updated probes connected and being tested 
Example of what the pressure sensor added to the C3PO may look like 

Updated Wiring diagram can be found in the:

wiring diagram folder → C3PO_SensorUpdate_Team_WiringDiagram

This wiring diagram shows how we connected the Interlink (which holds the probes) to the Boron (which transfers the information).
